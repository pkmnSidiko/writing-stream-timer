Using the timer elsewhere

OBS / Streamlabs

Add the timer as a Browser Source using this page with ?viewer at the end of the URL.

Viewer mode hides the controls and uses a transparent background, so you can place the timer over your stream layout.

Website / Embed

Use the ?embed version when you want a clean embedded timer on another website or workspace.

Embed mode hides the timer controls and uses a transparent background. The timer's saved settings are local to the browser where they were configured.
